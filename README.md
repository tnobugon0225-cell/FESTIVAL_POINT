# festival-points-v5.73-chat-dm-fix

## 原因
- v5.71 で DM モーダル内の
  - `.dm-head`
  - `.dm-messages`
  - `.dm-compose`
  - `#dmStatus`
  に `position: relative !important` を当ててしまい、
  それまでの **absolute配置ベースのモーダル設計** が崩れていました。
- その結果、個別メッセージ画面で
  - メッセージ欄
  - 入力欄
  - ステータス欄
  の並びが壊れ、余白や見切れが発生していました。
- 全体チャット側は v5.72 の吹き出しレイアウトが強すぎて、
  2行メッセージ時に時刻との距離感や、アイコンとのバランスに違和感が出ていました。

## 修正内容
- DM モーダルの absolute 配置を network ページ限定で復元
- DM の入力欄 / 送信ボタン / ステータス欄の位置を再調整
- 全体チャットの吹き出しを再調整
  - 時刻を本文のすぐ横に寄せる
  - 2行メッセージ時の伸びすぎ感を軽減
  - アイコン / 称号 / 吹き出しの縦位置を微調整
- RULE ページ下部CTA削除はそのまま維持
