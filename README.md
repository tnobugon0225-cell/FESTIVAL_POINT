# festival-points-v5.74-dm-chat-align-fix

## 今回の修正

### 1. 個別メッセージの「空いたまま・閉じづらい」不具合を修正
原因は、DM起動時に `dmUser` の参照が不安定なケースで
- 宛先名が空になる
- 読み込み失敗時に中身が真っ黒なままに見える
という状態が起きていたこと。

対応として：
- MESSAGE ボタン押下時に `data-dm-name` だけでなく、カード内の表示名もフォールバックに使用
- 不正な `userId` は開かないように防御
- DMオープン時に「読み込み中...」を表示
- 読み込み失敗時もメッセージ欄に状態を表示
- close処理を `closeDm()` として一本化し、中身・状態・入力値も確実に初期化
- モーダル外観のクリック優先度を見直し、閉じるボタンを押しやすく調整

### 2. 全体チャットの位置バランスを再調整
- アイコンの縦中央を吹き出しの縦中央に合わせる方向へ再調整
- それに合わせて称号・名前ブロックも中央寄せ
- 吹き出し左側の余白を統一して、長文時だけ詰まって見える違和感を軽減
- 時刻は本文のすぐ横に置いたまま、崩れにくい形に調整
